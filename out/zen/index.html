04Product Capabilities

Complete Feature Architecture

From unskippable app blockers and mindful breathing wait timers to on-device Gemma 3 1B AI classification, Zen Launcher is engineered for intentional living.

Focus & Wellbeing

Friction against impulse

Wait Timer

A short breathing countdown before an app opens. Breaks muscle-memory phone pickups and prevents subconscious mindless launches.

Unbypassable App Blocker

Lock out any app from 1 hour to 30 days. Auto-expires, strictly unskippable. Overlay window cannot be bypassed or closed.

Blocking Schedules

Block sets of apps automatically on chosen days and timeframes (supports overnight schedules e.g., 22:00 to 07:00).

Per-App Grayscale

Drains the color while a chosen app is open, eliminating high-contrast dopamine cues while leaving your phone normal elsewhere.

Quiet Notification Inbox

Intercepts distracting alerts and holds them safely in Zen's own local inbox. Review them on your schedule without status bar dings.

Screen Time Engine

True usage without inflation

Apps Tab

Productive-time switch, 7-day visual chart (Learn · Fun · Waste · rest of phone time; tap any day for numbers), and time per app today.

Websites Tab

Chrome tracking switch, time per site today grouped cleanly by domain, with its assigned Learn/Fun tag.

YouTube Tab

Dedicated switch; partitions today's watch time into Learn, Fun, Shorts, and untagged. Logs exact time per channel and per video.

Anti-Inflation Filter

Stuck screens (Recents view, incoming call screens, notification shades, system overlays) no longer artificially inflate active app time.

Media & Web Telemetry

Active watch duration only

Long Videos vs Idle

Only time actually playing media counts. Paused tabs or background idle do not inflate stats. Saves channel name and video title.

Shorts Isolation

Detected directly on screen via accessibility heuristics and isolated separately as Waste, distinct from long-form educational watch time.

Chrome Domain Tracking

Extracts top-level domains in real-time. Well-known domains (GitHub, Wikipedia, Arxiv) are pre-tagged from a built-in list.

User Tag Authority

Tap Learn or Fun on any channel or site. Your personal manual tag always wins over automated heuristics. Untagged items are surfaced first.

On-Device AI Tagging: Gemma 3 1B

Powered by Google MediaPipe GenAI · 100% Offline

Zero Network Calls

Autonomous Local Inference

Runs Google's Gemma 3 1B model natively on your phone's processor via MediaPipe. Completely free, works offline, and sends zero bytes over the air.

Gentle Background Tagging

Tags new channels and websites as Learn or Fun every 3 hours (only when battery is not low), 2 hours after first seen. Max 2 tries each; manual "Tag now" button.

One-Time Private Setup

Download the Gemma 3 1B model file (555 MB with a free Hugging Face account) once, pick it with Android's system file picker in Zen, and it is ready.

06Trust & Security

Privacy & Permissions: Each Strictly Optional

Zen Launcher has zero analytics SDKs, zero cloud tracking, zero remote servers, and zero telemetry. Every capability is powered strictly by local Android APIs.

100% Local SQLite DB

All usage metrics, schedules, favorites, and watch logs live solely inside an encrypted Room database on your physical device.

No Screen Scraping

Zen Focus sets canRetrieveWindowContent="false". It knows which app is open, but can never see what you read, write, or type.

Excluded from Backups

Your notification inbox and sensitive usage logs are explicitly excluded from Google Drive and Android cloud transfers (data_extraction_rules.xml).

Permission Manifest & System Access Map

Every permission is requested just-in-time only when you enable the corresponding feature.

Usage Access

Optional

Granted via Android Settings → Usage Access

Why it's needed: Calculates total app screen time, today's timeline bars, and screen-free breaks.

Under the hood: Reads standard Android UsageStatsManager event intervals. Does not read content.

Accessibility (Zen Focus)

Optional

Granted via Android Settings → Accessibility

Why it's needed: Powers wait timers, unskippable app blocking, per-app grayscale, YouTube Shorts isolation, Chrome domain tracking, and unlock rewards.

Under the hood: canRetrieveWindowContent is strictly FALSE. Only inspects the foreground package/activity class name. Never reads typed text, passwords, or on-screen content.

Notification Access

Optional

Granted via Android Settings → Notification Listener

Why it's needed: Tracks active YouTube video playback duration (via media session notifications) and routes distracting apps to Zen's quiet in-app inbox.

Under the hood: Filtered notifications are saved in a local Room database capped at the 200 newest items and completely excluded from cloud backups.

Write Secure Settings (ADB)

Optional · One-Time

Granted once via adb shell pm grant

Why it's needed: Enables per-app monochrome (system-level grayscale toggle).

Under the hood: Requires a single adb pm grant command. Completely optional if you don't use grayscale.

07Specifications & Transparency

Technical Specifications & Notes

Full technical clarity on what Zen includes, how it is built, and what to expect when sideloading.

Good to Know

Distribution via Direct APK

Not distributed on Google Play Store due to high-privilege focus permissions (Accessibility, Draw-Over-Apps, Notification Access). Download and install directly via GitHub Releases or build from source.

Package Size Breakdown

Full APK is ~27 MB, largely composed of Google's native MediaPipe GenAI on-device inference runtime. A ~2 MB ultra-lite build without on-device AI is also supported.

AI Model Download (555 MB)

The Gemma 3 1B LLM model weights are not bundled in the APK to keep installs nimble. Download the .task file once from Hugging Face for free and select it in Zen settings.

Browser Scope: Chrome

Website domain telemetry and tab tracking currently support Google Chrome. Support for Firefox and Brave is planned.

Metrics Retention Window

Per-app, per-site, and per-video breakdowns display granular logs for today. The 7-day overview chart summarizes rolling week trends across Learn, Fun, and Waste.

Video Titles Tracking

Video title logging is active from v0.1.0 onwards. Previous watch history displays aggregated channel-level duration.

While all permissions can be comfortably granted directly within the in-app Settings screen, you can also grant full permissions immediately over USB:

# 1. Overlay (Wait timer & unbypassable block screens)

adb shell appops set com.bibek.zen SYSTEM_ALERT_WINDOW allow

# 2. Accessibility (Foreground app detection & Zen Focus)

adb shell settings put secure enabled_accessibility_services com.bibek.zen/com.bibek.zen.service.accessibility.ZenAccessibilityService

# 3. Screen time stats & notification filter

adb shell appops set com.bibek.zen android:get_usage_stats allow

adb shell cmd notification allow_listener com.bibek.zen/com.bibek.zen.service.notification.ZenNotificationListenerService
