11:T8754,<p>A transformer looks at every token at once. Nothing in that operation records which token came first, so position has to be supplied deliberately.</p>
<p>RoPE supplies it by rotating each query and key vector by an angle set by its position. Nothing is added and nothing is concatenated — the vector is simply turned.</p>
<h2 id="why-position-has-to-be-injected"><a class="heading-anchor" href="#why-position-has-to-be-injected">Why position has to be injected</a></h2>
<p>Attention compares every token against every other. If you shuffle the input, you shuffle the outputs in the same way, and nothing else changes.</p>
<p>So <code>the dog bit the man</code> and <code>the man bit the dog</code> contain the same tokens and, without position information, produce the same result. The meaning lives entirely in the order, and the order is exactly what attention cannot see.</p>
<h2 id="what-was-done-before"><a class="heading-anchor" href="#what-was-done-before">What was done before</a></h2>
<p>The original approach was to build a vector for each position and add it to the token's embedding. Sometimes that vector was a fixed pattern of sines and cosines; sometimes it was learned.</p>
<p>Both work, and both have the same two weaknesses.</p>
<p>Adding mixes position into the same numbers that carry meaning — the model has to disentangle them afterwards. And what gets encoded is the <em>absolute</em> slot: position 5 and position 9 each get their own vector, with nothing in the arithmetic stating that they are four apart. Any sense of distance has to be learned from the data rather than falling out of the maths.</p>

<p>The first pair completes a full turn every six tokens, so it is a fine-grained marker useful only for telling near neighbours apart. <p>Between them the pairs cover every scale at once. That spread is what lets one mechanism handle both "the previous word" and "somewhere in the last few thousand".</p>

<p>Nothing enforces this. It is a property of rotation, and it arrives for free the moment you choose to encode position as an angle rather than as something to add on.</p>
<h2 id="what-it-costs"><a class="heading-anchor" href="#what-it-costs">What it costs</a></h2>
<p>Nothing, in parameters. There is no table of position vectors to learn and no extra weights — just a rotation applied to the queries and keys before the attention scores are computed.</p>
<p>It also degrades gracefully past the training length. A learned position table has no entry for position 6,000 if it was only ever trained to 4,000. RoPE has an angle for every position, because the formula keeps working; the model may not use very long distances well without adaptation, but there is no missing entry and nothing undefined. That is why the common tricks for stretching context — scaling or interpolating the frequencies — are adjustments to <span class="katex"><span class="katex-mathml"><math xmlns="http://www.w3.org/1998/Math/MathML"><semantics><mrow><msub><mi>θ</mi><mi>i</mi></msub></mrow><annotation encoding="application/x-tex">\theta_i</annotation></semantics></math></span><span class="katex-html" aria-hidden="true"><span class="base"><span class="strut" style="height:0.8444em;vertical-align:-0.15em;"></span><span class="mord"><span class="mord mathnormal" style="margin-right:0.0278em;">θ</span><span class="msupsub"><span class="vlist-t vlist-t2"><span class="vlist-r"><span class="vlist" style="height:0.3117em;"><span style="top:-2.55em;margin-left:-0.0278em;margin-right:0.05em;"><span class="pstrut" style="height:2.7em;"></span><span class="sizing reset-size6 size3 mtight"><span class="mord mathnormal mtight">i</span></span></span></span><span class="vlist-s">​</span></span><span class="vlist-r"><span class="vlist" style="height:0.15em;"><span></span></span></span></span></span></span></span></span></span> rather than new machinery.</p>
<h2 id="the-short-version"><a class="heading-anchor" href="#the-short-version">The short version</a></h2>
<ul>
<li>Attention sees a set of tokens, not a sequence, so position must be supplied.</li>
<li>Older methods added a position vector, which mixes position into meaning and encodes absolute slots rather than distances.</li>
<li>RoPE splits queries and keys into 2D pairs and rotates each pair by an angle proportional to the token's position.</li>
<li>Each pair rotates at its own frequency, from a full turn every six tokens to one every forty-seven thousand.</li>
<li>In the dot product the absolute rotations cancel and only the gap between the two tokens survives.</li>
<li>It adds no parameters, preserves vector length, and has a defined angle for any position.</li>
