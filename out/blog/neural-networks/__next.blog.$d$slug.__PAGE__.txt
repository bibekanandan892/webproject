5:T2246,<p>A neural network is a function with adjustable numbers inside it. You give it an input — pixels, words, sensor readings — and it produces an output — a label, a probability, the next word. Training means adjusting the numbers until the outputs are right on examples where the right answer is known.</p>
<p>That is the whole idea. Everything else is the specifics of what the function looks like and how the adjusting is done.</p>
<h2 id="one-neuron"><a class="heading-anchor" href="#one-neuron">One neuron</a></h2>
<p>The building block takes some inputs, multiplies each by a <strong>weight</strong>, adds them up with a <strong>bias</strong>, and passes the result through an <strong>activation function</strong>:</p>
<p><code>output = activation(w₁x₁ + w₂x₂ + … + b)</code></p>
<p>The weights say how much each input matters and in which direction. The bias shifts the threshold. The activation bends the result — a sigmoid squashes it into 0 to 1, a ReLU zeroes out negatives.</p>
<p>A single neuron draws one straight line (or flat plane) through the input space and says which side a point is on. That is enough for AND and OR. It is not enough for XOR.</p>
<h2 id="why-one-neuron-is-not-enough"><a class="heading-anchor" href="#why-one-neuron-is-not-enough">Why one neuron is not enough</a></h2>
<p>XOR is true when exactly one of two inputs is true:</p>






























<table><thead><tr><th>x₁</th><th>x₂</th><th>XOR</th></tr></thead><tbody><tr><td>0</td><td>0</td><td>0</td></tr><tr><td>0</td><td>1</td><td>1</td></tr><tr><td>1</td><td>0</td><td>1</td></tr><tr><td>1</td><td>1</td><td>0</td></tr></tbody></table>
<p>Plot the four points and try to draw one straight line with the 1s on one side and the 0s on the other. It cannot be done — the 1s are on one diagonal and the 0s on the other. No single neuron can compute XOR, whatever its weights.</p>
<h2 id="a-layer-in-between"><a class="heading-anchor" href="#a-layer-in-between">A layer in between</a></h2>
<p>Put a <strong>hidden layer</strong> of neurons between the inputs and the output. Each hidden neuron draws its own line; the output neuron combines them. Two lines can fence off the diagonal, so XOR becomes possible.</p>
<p>The network below has 2 inputs, 4 hidden neurons and 1 output, all with sigmoid activations. Counting weights and biases: <code>2×4 + 4 + 4×1 + 1 =</code> <strong>17 parameters</strong>. Starting from random weights, I trained it on the four XOR examples, measuring error as the mean squared difference between output and target:</p>



































<table><thead><tr><th>step</th><th>loss</th><th>outputs for (0,0) (0,1) (1,0) (1,1)</th></tr></thead><tbody><tr><td>1</td><td>0.3350</td><td>0.417 · 0.406 · 0.419 · 0.409</td></tr><tr><td>100</td><td>0.2879</td><td>0.488 · 0.504 · 0.496 · 0.508</td></tr><tr><td>500</td><td>0.0093</td><td>0.077 · 0.913 · 0.908 · 0.113</td></tr><tr><td>1,000</td><td>0.0011</td><td>0.030 · 0.968 · 0.968 · 0.040</td></tr><tr><td>5,000</td><td><strong>0.0001</strong></td><td><strong>0.010 · 0.990 · 0.990 · 0.013</strong></td></tr></tbody></table>
<p>At the start every output is about 0.41 — the network knows nothing and says roughly the same thing for everything. By step 100 it has only learned to say 0.5, the safest answer when unsure. Somewhere before step 500 the hidden neurons find useful lines, and the outputs split apart. By 5,000 steps it is right to two decimal places.</p>

<h2 id="how-the-weights-get-adjusted"><a class="heading-anchor" href="#how-the-weights-get-adjusted">How the weights get adjusted</a></h2>
<p>Each training step does four things:</p>
<ol>
<li><strong>Forward pass.</strong> Run the inputs through the network to get outputs.</li>
<li><strong>Loss.</strong> Measure how wrong the outputs are — here, the squared difference from the target.</li>
<li><strong>Backward pass.</strong> Use the chain rule to compute, for every weight, how much the loss would change if that weight changed slightly. This is <strong>backpropagation</strong>, and the resulting numbers are the <strong>gradient</strong>.</li>
<li><strong>Update.</strong> Nudge every weight a small step in the direction that reduces the loss. This is <strong>gradient descent</strong>; the size of the step is the <strong>learning rate</strong>.</li>
</ol>
<p>Repeat, thousands or millions of times. No one tells the hidden neurons what to detect. They end up detecting whatever makes the loss go down — in XOR, two diagonal boundaries; in an image model, edges, then textures, then parts of objects.</p>
<h2 id="scaling-up"><a class="heading-anchor" href="#scaling-up">Scaling up</a></h2>
<p>Nothing about the method changes as networks grow. Only the numbers do:</p>





















<table><thead><tr><th>network</th><th>parameters</th></tr></thead><tbody><tr><td>XOR, 2-4-1</td><td>17</td></tr><tr><td>handwritten digits, 784-128-10</td><td>101,770</td></tr><tr><td>a large language model</td><td>tens to hundreds of billions</td></tr></tbody></table>
<p>Larger networks add more layers ("deep" learning means many layers), wider layers, and specialised structures — convolutions for images, attention for sequences. But each layer is still weighted sums followed by a non-linear bend, and training is still forward, loss, backward, update.</p>
<p>The bend matters. Without activation functions, stacking layers achieves nothing: a sequence of weighted sums is itself just one weighted sum, and the deep network collapses into a single neuron that still cannot learn XOR.</p>
<h2 id="what-to-take-away"><a class="heading-anchor" href="#what-to-take-away">What to take away</a></h2>
<p>A neural network is layers of neurons, each a weighted sum plus a bias passed through a non-linear activation. One neuron can only draw a straight boundary; a hidden layer combines several boundaries into shapes no single line can make.</p>
<p>Training adjusts every weight by gradient descent, with gradients computed by backpropagation. A 17-parameter network learns XOR from four examples in a few thousand steps.
