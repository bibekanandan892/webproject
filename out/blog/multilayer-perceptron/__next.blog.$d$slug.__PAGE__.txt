5:T24c8,<p>The multilayer perceptron — MLP — is the original deep neural network and still one of the most used. It is a stack of fully connected layers: every neuron in one layer is connected to every neuron in the next, and each layer's output passes through a non-linear activation before the next layer sees it.</p>
<p><code>h₁ = activation(x W₁ + b₁)</code>
<code>h₂ = activation(h₁ W₂ + b₂)</code>
<code>y = h₂ W₃ + b₃</code></p>
<p>There is nothing else in it: no convolutions, no attention, no memory. Yet it can learn almost any input-output mapping, and it is a core component of every large language model.</p>
<h2 id="what-each-layer-adds"><a class="heading-anchor" href="#what-each-layer-adds">What each layer adds</a></h2>
<p>A single layer computes weighted sums, which can only describe flat relationships: straight lines, planes. The activation function is what adds shape. With ReLU — <code>max(0, z)</code> — each hidden neuron contributes a function that is zero on one side of a threshold and rises linearly on the other: a single <strong>kink</strong>.</p>
<p>Add those kinked pieces together with different thresholds and slopes and you can build any <strong>piecewise-linear</strong> curve. And piecewise-linear curves can follow any smooth curve as closely as you like, given enough pieces.</p>
<h2 id="how-many-neurons-a-curve-needs"><a class="heading-anchor" href="#how-many-neurons-a-curve-needs">How many neurons a curve needs</a></h2>
<p>Take one period of a sine wave. A hidden layer of <em>N</em> ReLU units can produce a curve with <em>N</em> straight segments — kinks at chosen points — and the best such curve follows the sine with an error that shrinks as segments are added:</p>

























<table><thead><tr><th>ReLU units</th><th>maximum error</th></tr></thead><tbody><tr><td>4</td><td>0.2105</td></tr><tr><td>8</td><td>0.0704</td></tr><tr><td>16</td><td>0.0188</td></tr><tr><td>32</td><td><strong>0.0048</strong></td></tr></tbody></table>
<p>Each doubling of the units cuts the error by about four. That is the intuition behind the <strong>universal approximation theorem</strong>: a network with one hidden layer and enough units can approximate any continuous function on a bounded range to any desired accuracy.</p>
<p>The theorem says it is <em>possible</em>. It does not say the number of units is small, or that training will find the weights. For complicated functions, a single wide layer can need astronomically many units. Depth helps: a second layer can fold and combine the first layer's pieces, so deep MLPs represent many functions with far fewer total neurons than shallow ones.</p>

<h2 id="counting-parameters"><a class="heading-anchor" href="#counting-parameters">Counting parameters</a></h2>
<p>Every connection is a weight and every neuron has a bias, so a layer from <em>a</em> inputs to <em>b</em> outputs has <code>a × b + b</code> parameters. A classic MLP for 28 × 28 handwritten digits, with hidden layers of 256 and 128:</p>
<p><code>784×256 + 256 + 256×128 + 128 + 128×10 + 10 =</code> <strong>235,146 parameters</strong></p>
<p>Almost all of them are in the first layer, because it connects to every pixel. That is the MLP's main weakness on images: it treats every pixel as an unrelated input, with no idea that neighbouring pixels belong together. A cat moved two pixels to the left is, to an MLP, an entirely new input. Convolutional networks were invented to fix exactly that.</p>
<h2 id="the-mlp-inside-every-transformer"><a class="heading-anchor" href="#the-mlp-inside-every-transformer">The MLP inside every transformer</a></h2>
<p>Each transformer layer has two parts. Attention moves information <em>between</em> positions in the sequence. Then an MLP — usually called the feed-forward network — processes <em>each position on its own</em>: expand the vector to about four times its width, apply an activation, project back down.</p>
<p>For a model of width 4,096:</p>

















<table><thead><tr><th>part of one transformer layer</th><th>parameters</th></tr></thead><tbody><tr><td>attention (queries, keys, values, output)</td><td>67M</td></tr><tr><td>MLP (4,096 → 16,384 → 4,096)</td><td><strong>134M</strong></td></tr></tbody></table>
<p>The MLP holds <strong>two-thirds</strong> of the layer's parameters, and therefore most of the model's. Research into what models store suggests much factual knowledge lives in these MLP weights: attention gathers the context, the MLP looks up and transforms what that context means. Mixture-of-experts models replace this one MLP with many smaller ones and route each token to a few — which is why "experts" are MLPs.</p>
<h2 id="training-it"><a class="heading-anchor" href="#training-it">Training it</a></h2>
<p>An MLP is trained like any network: forward pass, loss, backpropagation, gradient step. Practical concerns that apply to it directly:</p>
<ul>
<li><strong>Activation choice.</strong> ReLU and its smooth relatives (GELU, SiLU) train well in deep stacks; sigmoids saturate and slow learning in many layers.</li>
<li><strong>Initialisation.</strong> Weights must be scaled to the layer width so signals neither vanish nor explode as they pass through.</li>
<li><strong>Overfitting.</strong> With hundreds of thousands of parameters and modest data, an MLP can memorise; dropout, weight decay and early stopping keep it general.</li>
</ul>
<h2 id="what-to-take-away"><a class="heading-anchor" href="#what-to-take-away">What to take away</a></h2>
<p>A multilayer perceptron is fully connected layers with non-linear activations between them. Each ReLU unit contributes one kink, and enough kinks follow any smooth curve: 4 units fit a sine wave to within 0.21, 32 to within 0.0048. Depth lets layers combine pieces efficiently.</p>
