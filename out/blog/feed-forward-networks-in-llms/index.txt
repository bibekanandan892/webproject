11:T55b0,<p>Every transformer layer has two working parts. Attention is the one that gets discussed. The other is a small, ordinary neural network applied to each token, and it holds most of the parameters.</p>
<p>Attention is how tokens exchange information. The feed-forward network is what each token does with that information afterwards, on its own.</p>
<h2 id="where-it-sits"><a class="heading-anchor" href="#where-it-sits">Where it sits</a></h2>
<p>A transformer layer runs in this order:</p>
<ol>
<li>Multi-head attention</li>
<li>Add the input back, and normalise</li>
<li>Feed-forward network</li>
<li>Add the input back, and normalise</li>
</ol>
<p>The important detail is what "each token" means here. Attention lets tokens see each other. The feed-forward network does not — it processes every token <strong>completely independently</strong>, running the same weights over each one. Tokens are handled in parallel, but no information moves between them at this stage.</p>

<p>The vector goes in at 2,048 numbers, is pushed out to 8,192, and comes back at 2,048. Same size in, same size out — but transformed.</p>
<h2 id="why-widen-it-first"><a class="heading-anchor" href="#why-widen-it-first">Why widen it first</a></h2>
<p>The wide middle is where the work happens.</p>
<p>Each of those 8,192 hidden units is looking for one thing. A unit produces a large value when its particular pattern is present in the input and roughly nothing when it is not. With 8,192 of them, the layer can check for 8,192 different patterns at once.</p>
<p>Picture a parcel sorting office. Parcels arrive on one belt, get spread across a hall of sorting bays — one bay per destination — and then get consolidated back onto a single outbound belt. The hall has to be wider than the belt, or there is nowhere to do the sorting. The expansion is the hall.</p>
<p>The contraction then compresses whatever was found back into the width the next layer expects.</p>
<h2 id="the-activation-function"><a class="heading-anchor" href="#the-activation-function">The activation function</a></h2>
<p>Without an activation between the two matrix multiplies, the whole thing would collapse. Two matrix multiplies in a row are just one matrix multiply, and a stack of purely linear layers is a single linear layer no matter how deep. The activation is what makes depth mean anything.</p>
<p><strong>ReLU</strong> is the simplest: <span class="katex"><span class="katex-mathml"><math xmlns="http://www.w3.org/1998/Math/MathML"><semantics><mrow><mi>max</mi><mo>⁡</mo><mo stretchy="false">(</mo><mn>0</mn><mo separator="true">,</mo><mi>x</mi><mo stretchy="false">)</mo></mrow><annotation encoding="application/x-tex">\max(0, x)</annotation></semantics></math></span><span class="katex-html" aria-hidden="true"><span class="base"><span class="strut" style="height:1em;vertical-align:-0.25em;"></span><span class="mop">max</span><span class="mopen">(</span><span class="mord">0</span><span class="mpunct">,</span><span class="mspace" style="margin-right:0.1667em;"></span><span class="mord mathnormal">x</span><span class="mclose">)</span></span></span></span>. Anything negative becomes zero. That makes the hidden layer sparse — most units output nothing for any given token, and each learns to fire for its own kind of input.</p>
<p><strong>GELU</strong> softens the corner. Instead of cutting negatives off abruptly it lets small negative values through, scaled down. GPT and BERT use it.</p>
<p><strong>SwiGLU</strong> adds a gate. A third matrix produces a set of multipliers, and those scale the activated values elementwise — so the network learns not just what each unit computes but how much of it to let through.</p>
<p>That third matrix costs parameters, which is why models using SwiGLU shrink the expansion. Keeping the parameter budget fixed:</p>

<h2 id="where-the-knowledge-lives"><a class="heading-anchor" href="#where-the-knowledge-lives">Where the knowledge lives</a></h2>
<p>Attention works out relationships — which words relate to which. It does not store facts. The feed-forward network does.</p>
<p>Given <code>the tallest mountain is</code>, attention establishes that "tallest" modifies "mountain" and that the sentence is heading towards a name. The feed-forward network is what makes that name Everest. Units that learned geographic associations during training fire, and their contribution pushes the output vector towards the right answer.</p>
<p>That is why these layers are described as the model's memory. The patterns are distributed across thousands of units rather than stored in any single place, but the facts a model can recall live here.</p>
<h2 id="two-thirds-of-the-parameters"><a class="heading-anchor" href="#two-thirds-of-the-parameters">Two thirds of the parameters</a></h2>

<p>Two thirds of every layer. In a large model that is the majority of the total parameter count, sitting in the part that gets talked about least.</p>
<h2 id="splitting-it-into-experts"><a class="heading-anchor" href="#splitting-it-into-experts">Splitting it into experts</a></h2>
<p>Because the feed-forward network is so much of the model, it is also the part worth making conditional.</p>
<p>Mixture-of-experts replaces the single feed-forward network with several smaller ones and adds a router that picks which ones each token goes through. The model keeps a large total parameter count, but any individual token only activates a fraction of it. The expansion, activation and contraction inside each expert work exactly as described above.</p>
<h2 id="the-short-version"><a class="heading-anchor" href="#the-short-version">The short version</a></h2>
<ul>
<li>Every transformer layer pairs attention with a feed-forward network.</li>
<li>Attention moves information between tokens; the feed-forward network transforms each token on its own.</li>
<li>It expands the vector about 4×, applies an activation, and contracts it back.</li>
<li>The wide middle gives room for thousands of pattern detectors; the activation is what stops the two multiplies collapsing into one.</li>
<li>SwiGLU adds a gating matrix and drops the expansion to about 2.7× to keep the parameter count level.</li>
<li>Roughly two thirds of a layer's weights are here, and so is most of what the model knows.</li>
